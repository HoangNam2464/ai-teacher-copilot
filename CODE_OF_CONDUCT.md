# Code of Conduct

> Applies to all contributors, maintainers, and users of the **AI Teacher Copilot for K-12 Teachers** project.

---

## Our Pledge

We as contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone, regardless of age, technical background, experience level, nationality, personal appearance, race, religion, or personal identity.

As an **educational AI project** designed to support K-12 teachers, we additionally commit to:

- Respecting the professional environment and values of educators
- Protecting student privacy absolutely — Student PII is strictly out of scope for this project
- Developing AI responsibly — transparent, verifiable, with teachers as the final decision-makers

---

## Our Standards

### Encouraged Behavior

- Demonstrating empathy and kindness toward other people
- Being respectful of differing opinions, viewpoints, and experience levels
- Giving and gracefully accepting constructive feedback
- Accepting responsibility and learning from mistakes
- Focusing on what is best for the project and the educational community it serves
- Sharing knowledge openly without judging others' skill level
- Reporting bugs and security vulnerabilities responsibly through proper channels

### Unacceptable Behavior

- Use of offensive, discriminatory, or sexualized language or imagery
- Personal attacks, political attacks, trolling, or harassment of any kind
- Publishing others' private information without explicit permission
- Deliberately exploiting security vulnerabilities to compromise the system or its data
- Using this project to process, store, or expose Student PII in any form
- Falsifying AI-generated outputs or citations to deceive end users or educators

---

## Scope

This Code of Conduct applies within all project spaces, including:

- GitHub Issues, Pull Requests, and Discussions
- Commit messages and code review comments
- Any communication channel related to this project

## Enforcement Guidelines

Community maintainers will follow these guidelines when determining consequences:

| Level | Violation | Consequence |
| :---: | :--- | :--- |
| **1 — Correction** | Inappropriate language or minor unprofessional behavior | Private written warning with explanation |
| **2 — Warning** | Single incident or series of inappropriate actions | Formal warning + temporary interaction restriction |
| **3 — Temporary Ban** | Serious violation or sustained harassment | Temporary ban from all community interaction |
| **4 — Permanent Ban** | Systematic violations, intentional data harm, or exploitation of student data | Permanent ban from the project |
